# Eclectic Golf Scorecard – web pages

Public pages for the Eclectic Golf Scorecard app, served free by GitHub Pages:

- `index.html` – "Get the app": sends Android phones to Google Play and iPhones to the App Store (the app's QR code points here).
- `privacy.html` – the privacy policy linked from Google Play and the App Store.

Edit the copies in the app repository's `docs/` folder, then copy them here.
